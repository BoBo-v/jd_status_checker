# 京东商品上下架与风控状态自动化巡检系统

基于 **Python + DrissionPage + OpenPyXL** 构建的电商数据自动化巡检 RPA 工具。实现从 Excel 表格自动读取京东 PC/移动端商品链接、仿真移动端 H5 绕过/降低登录验证、多分支识别商品在售/下架/风控状态，并实时回写结果至 Excel，支持断点续传、人机协作过验与异常自动截图。

---

## 🌟 核心功能模块

### 1. 数据读取与 URL 标准化模块（输入层）
* **智能表头识别**：基于关键词模糊匹配定位核心列（如 `京东链接（必填）`、`是否已下架（1下架）`），无需用户手动调整原始表头顺序。
* **缺列自动补全**：若原表格无 `检测备注/异常状态` 或 `检测时间` 列，程序会自动在末尾追加，不破坏原表格公式与格式排版。
* **PC 转移动端 H5**：支持 PC 链接（`item.jd.com/{sku}.html#crumb-wrap`）、短链接、纯数字 SKU 等多种输入格式，通过正则提取 `skuId` 拼接为移动端 H5 链接 `https://item.m.jd.com/product/{skuId}.html`，绕过 PC 端的强制登录壁垒。

### 2. 移动端仿真与反风控模块（采集层）
* **移动端指纹伪装**：底层直接配置移动端 User-Agent（iPhone / Android）与移动端视口分辨率（390×844），原生启用触屏支持（`TouchEvents`）。
* **免自动化标识**：无 WebDriver 特征，移除已被 Chromium 警告的 `--disable-blink-features`，还原纯天然浏览器窗口。
* **持久化登录态（Cookie 复用）**：自动保存浏览器 Profile 目录缓存；若遇到滑块或扫码登录，可在弹出的真实窗口中完成，登录态自动长期保留。
* **无痕模式切换**：支持 `--incognito` 一键开启纯净无痕浏览器会话。
* **随机防封延时**：每次检测之间随机休眠 `3.5~7 秒`，平滑访问节奏。

### 3. 多维状态判定嗅探与人机协同机制（核心逻辑层）
多重 DOM 与页面文本特征分支判定规则：

| 页面状态分类 | 页面特征（判定依据） | 【是否已下架】回写值 | 【检测备注/异常状态】回写值 |
| :--- | :--- | :---: | :--- |
| **正常上架** | 存在“立即购买”、“加入购物车”、“领券购买”等购买按钮，且无下架提示 | `0` | 正常在售 |
| **下架状态 A (商品页留存)** | 出现黄色提示条“此商品已下架，推荐查看相似商品”，底部按钮变为“查看相似商品” | `1` | 已下架（展示相似推荐） |
| **下架状态 B (弹窗拦截)** | 背景置灰，弹出模态框“该商品已下架”（含“逛逛首页/搜索商品”按钮） | `1` | 已下架（弹窗完全下架） |
| **停售状态** | 页面出现“此商品已停售” | `1` | 已停售 |
| **无货状态** | 提示“所选地区暂时无货”或“暂无报价”（可配置是否计为下架） | `0` (可配 1) | 在售但当前区域无货 |
| **触发 CFE 购物无忧** | 页面跳转至 `cfe.m.jd.com` 或出现“验证一下，购物无忧” | `待查` (可人工过验) | 触发安全验证（CFE购物无忧拦截） |
| **触发登录验证** | 页面重定向至 `plogin.m.jd.com` 或 `passport.m.jd.com` | `待查` | 触发强制登录拦截 |
| **触发安全风控** | 出现滑块拼图、验证码、或“访问过于频繁/网络开小差” | `待查` (可人工过验) | 触发验证码风控，需验证 |
| **商品不存在/失效** | 提示“商品不存在”、“404”或自动重定向至移动端首页 | `1` | 商品不存在或重定向至首页 |
| **链接格式错误** | 表格内填入的链接无法提取有效 SKU | `异常` | 商品链接格式错误，无法提取SKU |
| **未知状态** | 未命中上述规则，自动对当前屏幕截图保存至 `error_screenshots` | `待查` | 未知状态，请查看截图 |

> [!IMPORTANT]
> **人机协作过验机制（Human-in-the-loop）**：
> 在窗口运行模式下，一旦触发 `cfe.m.jd.com`（“验证一下，购物无忧”）或滑块验证，控制台将**自动暂停并输出醒目提示**。你只需在弹出的浏览器中手动点击【快速验证】过验，回到控制台按一次 `Enter 回车键`，程序将自动重新检测该商品并继续后续巡检！

### 4. 实时回写与断点续传（输出层）
* **逐行实时保存**：默认每完成 1 个商品立即将结果回写保存至 Excel，防止断网、异常崩溃导致进度丢失。
* **智能断点续传**：启动时自动扫描已有结果，跳过已标记为有效状态（`0` 或 `1`）的行；支持只针对“待查/异常”行进行重新补测。
* **原表格保护**：使用 `openpyxl(data_only=False)`，保留原表格的所有计算公式、背景颜色与图片排版。

## 📁 目录结构

```text
jd_status_checker/
│
├── config.py                 # 全局配置参数（延时、无痕、自动暂停等）
├── url_parser.py             # URL 提取与 PC->H5 标准化模块
├── browser_manager.py        # 浏览器驱动（触屏事件支持、无痕/持久化管理）
├── detector.py               # 页面特征多维判定与状态嗅探核心逻辑
├── excel_handler.py          # Excel 读取、解析、回写与断点恢复
├── inspector.py              # 批量巡检主控制器与人机协同暂停调度
├── main.py                   # 启动入口（支持 CLI 传参或无参数交互向导）
├── create_sample_excel.py     # 测试样例生成脚本
├── requirements.txt          # Python 依赖项清单
├── run.bat                   # Windows 一键双击运行脚本
├── browser_data/             # 浏览器持久化缓存与 Cookie 目录（自动创建）
└── error_screenshots/        # 异常/待查商品截图归档目录（自动创建）
```

## 🚀 快速使用指南

### 1. 安装依赖环境
```bash
pip install -r requirements.txt
```

### 2. 方式 A：双击一键运行（推荐）
直接双击运行目录下的 **`run.bat`** 文件：
1. 自动扫描桌面与当前目录下的 `.xlsx` 文件供你按数字选择；
2. 支持交互选择是否开启无痕模式、是否开启无头静默；
3. 遇到 CFE 验证时，在弹出的窗口中手动点击一次过验，按回车继续即可。

### 3. 方式 B：命令行运行

* **基本巡检运行（推荐，保留窗口与持久化登录态）**：
  ```bash
  python main.py --excel "C:\path\to\your_goods.xlsx"
  ```

* **开启无痕模式（不记录历史与Cookie）**：
  ```bash
  python main.py --excel "C:\path\to\your_goods.xlsx" --incognito
  ```

* **风控时自动清除会话 Cookie 与缓存**：
  ```bash
  python main.py --excel "C:\path\to\your_goods.xlsx" --clear-on-risk
  ```

* **无头后台运行（静默模式，遇到验证码不等待直接标记待查）**：
  ```bash
  python main.py --excel "C:\path\to\your_goods.xlsx" --headless --no-pause
  ```

* **仅重测历史记录中的异常/待查行**：
  ```bash
  python main.py --excel "C:\path\to\your_goods.xlsx" --recheck-errors
  ```
